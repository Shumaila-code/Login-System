# 🔐 Login System

A simple Python console-based Login System developed using File Handling, Loops, Conditional Statements, and Functions (coming in the next version).

## 🚀 Features

- User Registration
- User Login
- View All Users
- Change Password
- Delete User Account
- File Handling using `users.txt`

## 🛠 Technologies Used

- Python
- File Handling
- Loops
- Conditional Statements

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Run:

```bash
python login.py
```
